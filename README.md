# КП · админка (Webtex)

Статическое приложение без сервера: открывается на GitHub Pages бесплатно. Список КП → редактор → PDF.

## Запуск на GitHub Pages
1. Создайте **публичный** репозиторий (на бесплатном плане Pages только для публичных), загрузите содержимое этой папки в корень.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / root. Через минуту сайт будет доступен.
3. Локально: `python3 -m http.server` в этой папке.

## Где хранятся КП
- Автоматически — в браузере (localStorage).
- Чтобы работать с нескольких компьютеров: создайте **отдельный приватный** репозиторий для данных (цены клиентов не должны быть публичными), выпустите Fine-grained token (Contents: read/write только на него), впишите в «Настройки». Кнопки «⬇ Загрузить / ⬆ Сохранить в GitHub» на главной.
- Резервная копия: «Экспорт JSON».

## Google-таблица
Доступ «все, у кого есть ссылка — просмотр». Ссылку вставьте в «Настройки». Формат листа — `sheet-template/smeta.csv`
(одна строка = одна строка сметы; строка без «этапа» с «итого» задаёт сумму тарифа без сметы):

| колонка | смысл |
|---|---|
| проект | должно совпасть с «Ключом проекта» в КП (по умолчанию — название клиента) |
| cms | вариант (Битрикс / WordPress …) |
| тариф | Базовый / Премиум / любой |
| этап, ставка, часы | строка сметы (стоимость = ставка × часы) |
| фикс | фиксированная сумма вместо ставки×часы |
| итого | сумма тарифа, если сметы нет |
| месяцев | срок рассрочки (0/пусто — блок скрыт) |

«Обновить цены из таблицы» во вкладке «Тарифы и цены»; при выгрузке в PDF цены подтягиваются сами (настраивается).
Если включено «Таблица сама включает только те тарифы…», то тарифы/CMS, которых нет в таблице, отключаются автоматически.

## Что считается автоматически
Итог сметы, часы, три платежа (доли настраиваются, последний = остаток, без копеечных расхождений), рассрочка = итог / месяцев,
слайд «Порядок оплаты» — по одному на каждый включённый вариант CMS, «Смета» — по одному на каждый тариф со строками.

## PDF
Кнопка «Скачать PDF» → страница предпросмотра → «Печать» → *Сохранить как PDF*, поля «Нет», «Фоновая графика» ✓. Страницы 1920×1080.
Добавьте `?auto=1` в конец адреса `#/print/…`, чтобы окно печати открывалось само.

## Шаблон
Кнопка «Шаблон КП» на главной: порядок и тексты слайдов, которые копируются в каждое новое КП.
В шаблоне по Figma-макету уже заведены типы слайдов; тексты с пометкой «ЗАМЕНИТЕ» нужно один раз заменить на реальные.
