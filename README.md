# КП · админка Webtex

Статическое приложение (без сервера) для GitHub Pages. Слайды — точная копия макета Figma «КП | Клиентам».

## Запуск
1. Загрузите **содержимое** этой папки (index.html, css/, js/, assets/, README.md) в репозиторий.
2. Settings → Pages → Deploy from a branch → `main` / root.
3. Откройте `https://<логин>.github.io/<репозиторий>/`.
Локально: `python3 -m http.server` в этой папке.

## Как это устроено
- **Статичные слайды** (команда, преимущества, ошибки, технологии и т. д.) — картинки 2× из макета (`assets/*.webp`). Можно включать/выключать и переставлять.
- **Динамические слайды** собираются по измеренной геометрии макета: обложка (клиент, срок действия), блок по CMS (сравнение тарифов, порядок оплаты, сметы), доп. расходы.
- Для каждой CMS (Битрикс, WordPress…) — свои тарифы. У тарифа переключатели: **Сравнение / Оплата / Смета**, колонка профиля сравнения (Нейро / Базовый / Премиум), рассрочка (авто по сумме).
- Всё считается само: итог сметы, часы («683 часа»), 3 равных платежа, рассрочка = итог / месяцев.

## Google-таблица
Доступ к таблице: «все, у кого есть ссылка — просмотр».
- **Проще всего:** «+ Новое КП» → вставьте ссылку на таблицу. Таблица загружается прямо в окне; редактор откроется, когда цены, тарифы и доп. расходы уже заполнены (название клиента берётся из ячейки «Клиент/Заказчик/Компания/Проект», иначе введите вручную). Берётся лист, открытый по ссылке. Повторно — кнопка «↻ Из таблицы» вверху редактора.
- Если у КП несколько CMS, для второй и следующих укажите «лист таблицы» во вкладке «Тарифы и цены».
- Можно вместо этого задать одну общую таблицу в «Настройках»: тогда лист ищется по названию клиента (или задайте лист для каждой CMS).
Структуру админка определяет сама: ищет блоки с заголовками «Задача | Стоимость часа | Кол-во час. | Стоимость услуг», имя тарифа — в ячейке над «Задача» (Нейро / База / Премиум / любое), читает строки до «Итого», пропускает задачи с нулевой стоимостью,
SEO-строки без ставки берёт как фиксированную сумму, «Рассрочка на N» под «Итого» — как срок рассрочки («-» — без рассрочки), блок «Дополнительные расходы» — как таблицу доп. расходов. «База» → «Базовый». Тарифы, которых нет в листе, отключаются.
SEO-строки без ставки берёт как фиксированную сумму, блок «Дополнительные расходы» — как таблицу доп. расходов. «База» → «Базовый». Тарифы, которых нет в листе, отключаются.
Рассрочка по сумме: до 300 тыс. — 4 мес., до 500 — 6, до 800 — 8, до 1,2 млн — 10, больше — 12 (меняется в «Настройках»; ниже 150 тыс. рассрочки нет).

## Порядок оплаты
Выберите слева страницу «Порядок оплаты · <CMS>» — под превью появится таблица настройки:
- **Этапы** — по одному в строке (общие для КП): можно переименовать, добавить, убрать.
- **Ячейка тариф × этап:** пусто — авто (остаток делится поровну), `-` — прочерк, `30%` — доля, `100000` — сумма, любой текст — как есть.
- **Скидка** — строка выделена цветом; у каждого тарифа тумблер и процент. Рядом в скобках видно, сколько это в рублях (только в админке, на слайд не идёт). На слайде — строка «Стоимость со скидкой N%» (у тарифов без скидки — прочерк); этапы считаются от цены со скидкой, рассрочка — от полной. Из таблицы скидка берётся из строки «Скидка N%» под «Итого», если там стоит сумма (тумблер включится сам; прочерк ручную скидку не стирает).
- Из таблицы подтягиваются «100% предоплата» (вся сумма в первом этапе) и «Рассрочка на N».

## PDF
«Скачать PDF» → страница предпросмотра с двумя кнопками:
- **⬇ Сохранить в PDF** — сразу скачивает файл «КП — <клиент>.pdf» (страницы 1920×1080, слайды сохраняются картинками, текст в файле не выделяется).
- **🖨 Печать** — окно печати браузера (там же можно «Сохранить как PDF» с выделяемым текстом: поля «Нет», «Фоновая графика» ✓).

Цены перед выгрузкой подтягиваются из таблицы (если включено).

## Данные
В браузере (localStorage); общий доступ — через **приватный** репозиторий с данными и токеном (Contents: read/write) в «Настройках». Резерв — «Экспорт JSON».

## Шрифт
Слайды и админка набраны шрифтом **Inter** (Google Fonts, подключается автоматически). Статичные слайды — картинки из макета, текст на них не меняется.
