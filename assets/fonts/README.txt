Положите сюда файлы шрифта Atyp Display (если есть лицензия) с ТОЧНО такими именами:
  AtypDisplay-Regular.woff2   (400)
  AtypDisplay-Medium.woff2    (500)
  AtypDisplay-Semibold.woff2  (600)
Допустимы также .woff / .otf / .ttf с теми же именами. Админка подхватит их автоматически, ничего менять не нужно.
